# Botanical product clinical research program: protocol portfolio

**Version:** 0.1.0  
**Status:** Protocol development

## Scope

This package indexes four independently maintained planning tracks: pain, sleep, anxiety, and focus. It does not combine their populations, interventions, outcomes, or designs into a single study.

## Current evidence state

The source repositories contain draft protocol and research-book materials plus analysis examples. This package includes no participant-level data and reports no clinical outcomes. Draft workbook fields and unresolved decisions are not protocol decisions.

## Methods and data governance

No pooled analysis is appropriate until each protocol has a finalized design, intervention and comparator, eligibility criteria, outcome/timepoint definitions, analysis plan, responsible party, consent, ethics review, and data-management plan. Any human data must be governed and de-identified under the approved protocol.

## Study-specific materials

See the [pain](https://github.com/Terpedia/trial-2026-pain), [sleep](https://github.com/Terpedia/trial-2026-sleep), [anxiety](https://github.com/Terpedia/trial-2026-anxiety), and [focus](https://github.com/Terpedia/trial-2026-focus) repositories. Each has an example analysis notebook; examples are not evidence of completed enrollment or results.

## Reproducibility

The index notebook lists the included indication notebooks. No trial analysis was run for this package. The data manifest is intentionally empty until public or approved study datasets are available.
